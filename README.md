# K. Agyemang Auto Parts website

Static website (HTML, CSS, JavaScript) for GitHub Pages. All files sit together in the top level of the repository, with no folders.

## Update the live site
1. Unzip the download.
2. Open github.com/DavidAgyemang/k-agyemang-auto-parts and click Add file, then Upload files.
3. Drag in every file from the unzipped folder (not the folder itself) and commit.
4. Wait one to two minutes, then open the site and hard refresh (Ctrl+Shift+R, or close and reopen the tab on a phone).
5. Open /check.html on the site. It lists every file and shows any that are missing. Delete check.html afterwards.

## Change contact details
Edit config.js: WhatsApp, phone, email, Instagram, TikTok, LinkedIn. Kumasi call lines are in contact.html.

## Requests
The Request a Part form builds a message in the visitor's browser and opens WhatsApp. Nothing is stored. Photos must be attached by the customer in WhatsApp.
